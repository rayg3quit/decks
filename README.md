## How It Works
- Each deck is a self-contained reveal.js HTML file in its own directory
- GitHub Pages serves them at `rayg3quit.github.io/decks/<deck-name>/`
- Simon pushes new decks via the GitHub API
- Landing page (index.html) auto-lists all available decks

## Security
For Cloudflare Access protection, CNAME this to a domain behind Cloudflare Zero Trust.
